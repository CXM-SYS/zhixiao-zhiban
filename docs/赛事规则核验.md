## 与本项目直接相关的规则

- 申报方向：职业发展赛。
- 选题：赛题 1“职场通用效能智能体”。页面描述的场景包括会议纪要整理、文档处理、数据统计、公文写作和日程事务等通用办公功能。
- 面向对象：开发者、团队、高校、独立开发者、职场人员和学生等。
- 作品说明：PDF，3—10 页。
- 演示材料：MP4，2—3 分钟。
- 作品交付：可运行的智能体链接（平台分享链接或网页地址）及使用说明；如果不能提供在线链接，准备源代码和部署说明 ZIP。

## 本项目采用的执行口径

- 产品名称：职效智办——职场通用效能智能体。
- 演示输入：用户需求、办公材料、CSV 任务表和周报草稿。
- 演示输出：需求理解、文档摘要、待办清单、表格问题、依据提示和人工确认事项。
- 部署方案：扣子 Bot + 工作流 + OpenAPI 插件；本地 Python 服务只用于回放和测试。
