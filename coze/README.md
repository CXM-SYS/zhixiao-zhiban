# 扣子接入包

这个目录包含把“职效智办”接入扣子所需的提示词、工作流设计和 OpenAPI 插件描述，对应职业发展赛的“职场通用效能智能体”方向。

## 推荐接入方式

1. 在扣子创建 Bot，名称使用“职效智办——职场通用效能智能体”。
2. 将 `bot_prompt.md` 的内容放入 Bot 的系统提示词。
3. 创建插件，导入 `openapi.yaml`，把服务地址替换为部署后的 HTTPS 地址。
4. 在工作流中按 `workflow_spec.md` 配置四个输入和插件调用。
5. 使用 `demo_payload.json` 和 examples 目录中的材料进行回放。

赛事页面显示，作品说明 PDF 为 3—10 页，演示视频为 2—3 分钟，并需提供可运行智能体链接及使用说明；不能提供在线链接时准备源代码和部署说明 ZIP。报名系统的最新要求优先。

## 本地回放

在项目根目录运行：

    python -m mozhi_yansuan serve --host 127.0.0.1 --port 8787

本地服务不能直接作为扣子插件地址；扣子插件需要公网可访问的 HTTPS 地址。可以先用本地回放验证输入输出，再部署到具备 HTTPS 和鉴权的服务环境。
